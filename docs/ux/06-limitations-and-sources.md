## Material limitations

- I could inspect the current GitHub repository, relevant live issue contracts, and current code paths, but the public deployment at `torn.geromet.com` was not discoverable/openable through the available web tool. This is therefore a code-and-contract UX audit, not a pixel-accurate browser audit of the deployed site.
- Heuristic ratings in the final report are expert-evaluation judgments, not user-study measurements.
- The proposed exact colors/sizes are starting tokens and must be validated against actual rendered states/contrast before adoption.
- Competitor feature descriptions are based on their current public pages, not authenticated hands-on testing.
